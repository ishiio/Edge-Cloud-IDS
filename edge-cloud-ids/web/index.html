Your workspace. Two ways to explore.
Browse immediately
Open OPEN_DASHBOARD.html in the extracted project folder. Browse real dataset previews, download CSVs, and explore saved evaluation results without Python.
Run the full application
Double-click START_WINDOWS.cmd on Windows, or run python3 launch.py on macOS / Linux. The launcher sets up a local environment and opens your browser.
Live replay and new flow classification require the server. Leave its terminal open while using these features.
